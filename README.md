# PHP Login/Register Project

This project is a simple login and registration system built with PHP.  
It includes the following files:

- `index.php` : Home page  
- `login.php` : Login form  
- `registration.php` : Registration form  
- `logout.php` : Logout functionality  
- `database.php` : Database connection  
- `style.css` : Website styling  
- `login_register.sql` : Database structure

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Abdelhamiid20/login-register-main.git
```
2. Import `login_register.sql` into your MySQL database.

3. Update `database.php` with your MySQL credentials.

4. Open `index.php` using a local server _like XAMPP, WAMP, etc._
